01

var, let, const

var

  • Function / global scoped
  • Redeclare: allowed
  • Reassign: allowed
  • Hoisted & initialized as undefined
  • No TDZ

let

  • Block scoped
  • Redeclare: not allowed
  • Reassign: allowed
  • Hoisted, not initialized
  • In TDZ until declared

const

  • Block scoped
  • Redeclare: not allowed
  • Reassign: not allowed
  • Hoisted, not initialized
  • In TDZ until declared
scope-demo.js

02

Arrow functions

An explicit return keeps the function body in braces with a return statement. An implicit return drops the braces and the value of the single expression is returned automatically.

arrows.js
const addExplicit = (a, b) => {
  return a + b;
};

const squareExplicit = (n) => {
  return n * n;
};

const addImplicit = (a, b) => a + b;
const squareImplicit = (n) => n * n;

console.log(addExplicit(3, 4));
console.log(squareImplicit(5));

04

Rest parameter vs spread syntax

Rest (...args) collects many arguments into a single array inside a function signature or destructuring pattern. Spread (...arr) does the opposite — it expands an array or object into individual elements, used in calls, array literals, or object literals.

rest-spread.js
function sumAll(...nums) {
  return nums.reduce((total, n) => total + n, 0);
}
console.log(sumAll(1, 2, 3, 4));

const partA = [1, 2, 3];
const partB = [4, 5, 6];
const merged = [...partA, ...partB];
console.log(merged);

function loadData() {
  return new Promise((resolve) => {

10

ES5 → ES6+

before.js — ES5
var name = "Ravi";
var age = 25;

var student = {
  name: name,
  age: age
};

var greet = function(name) {
  return "Hello " + name;
};

console.log(greet(name));
after.js — ES6+
const name = "Ravi";
const age = 25;

const student = { name, age };

const greet = (name) => `Hello ${name}`;

console.log(greet(name));

WHY THE ES6+ VERSION WINS

  • const/let replace var, giving block scope and preventing accidental reassignment or redeclaration.
  • Template literals replace string concatenation, making interpolated strings easier to read and edit.
  • Object shorthand { name, age } removes the repeated key: value pairing when the variable name matches the property name.
  • Arrow functions are shorter, and for callbacks they don't rebind this the way a regular function expression does.
